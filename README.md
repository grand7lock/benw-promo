# BENW · 미리 맞춘 개학

**1차 전환 랜딩 페이지** — 스폰지클럽 3기 2회차 과제 (2조 주주/김태완)

> 배포: https://benw-promo.vercel.app

---

## 이 페이지가 하는 일

가방을 파는 페이지가 **아닙니다.** 9월 1일 세트 오픈을 알려줄 수 있도록,
**스마트스토어 알림받기 + 카카오톡 채널**에 사람을 넣는 것이 목적입니다.

```
설문 3문항 + 사이즈 선택  →  가두리망 진입  →  개학 키트 PDF
       (1단계)                  (2단계)            (3단계)
```

**받는 순서가 핵심입니다.** 아이템(PDF)은 가두리망에 들어온 **다음에만** 줍니다.
먼저 주면 받고 그냥 나갑니다.

---

## GTM 코어와의 연결

> **"우리는 가방을 파는 게 아니라, 자기 상황을 알고 고르게 되는 상태를 판다."**

문의 1위도 사이즈, 반품 사유 1위도 사이즈, 재구매 이유도 사이즈였습니다.
그래서 이 페이지는 **신발주머니 3사이즈를 직접 고르게** 합니다. 값은 셋 다 같습니다.

## 설정

`.env.example` 을 복사해 `.env.local` 을 만들고 채웁니다.

| 변수 | 무엇 | 없으면 |
|---|---|---|
| `SUPABASE_URL` | 프로젝트 URL | 저장만 건너뜀 (페이지는 정상) |
| `SUPABASE_SERVICE_KEY` | 시크릿 키 (서버 전용) | 위와 같음 |
| `NEXT_PUBLIC_STORE_URL` | 스마트스토어 알림받기 주소 | 버튼이 `#` 로 동작 |
| `NEXT_PUBLIC_KAKAO_URL` | 카카오톡 채널 주소 | 위와 같음 |
| `NEXT_PUBLIC_KIT_URL` | 개학 키트 PDF 주소 | 위와 같음 |

**키가 없어도 신청 흐름은 끊기지 않습니다.** 저장만 건너뛰고 화면은 그대로 진행됩니다.

### 데이터베이스

Supabase → SQL Editor 에 [`supabase-schema.sql`](supabase-schema.sql) 을 붙여넣고 Run.
